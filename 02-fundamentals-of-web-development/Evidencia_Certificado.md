# Evidencia del Desarrollo de la Certificación

A continuación, se describen los conocimientos esenciales adquiridos durante cada módulo de la certificación en **Desarrollo Web**.

## Módulo 1: Aspectos básicos del desarrollo web  
Durante este módulo se revisaron los principios fundamentales del desarrollo web y el funcionamiento interno de internet. Se abordó el modelo cliente-servidor, el rol de los navegadores y los servidores, además de las herramientas utilizadas habitualmente por los desarrolladores. También se explicó cómo está conformada una página web y de qué manera las distintas tecnologías trabajan en conjunto para construir sitios web.

## Módulo 2: Desarrollo de sitios para la web  
Este módulo se centró en el diseño y estructuración de sitios web eficaces. Se estudió cómo organizar adecuadamente las páginas, cómo diseñar una navegación intuitiva y la importancia de crear experiencias centradas en el usuario. Se trabajó en el orden lógico del contenido y se aplicaron principios de usabilidad y accesibilidad.

## Módulo 3: Introducción a HTML y CSS  
Se introdujeron los lenguajes clave para construir sitios web: HTML y CSS. Se aprendió a definir la estructura de una página mediante etiquetas semánticas y a aplicar estilos visuales con CSS. Se adquirieron competencias para distribuir elementos, aplicar estilos visuales y manejar el diseño visual de los sitios web.

## Módulo 4: Creación de sitios web dinámicos con JavaScript  
Este módulo abordó el uso de JavaScript para dotar de interactividad a las páginas web. Se practicó la manipulación del DOM, la gestión de eventos y la implementación de lógica básica para responder a acciones del usuario. También se introdujeron elementos clave de programación como variables, estructuras de control y funciones.

## Módulo 5: Prueba y despliegue de sitios web  
Se estudió cómo verificar el correcto funcionamiento de un sitio a través de pruebas prácticas. Se aprendió a identificar errores y problemas de usabilidad, así como a subir el proyecto a un entorno accesible públicamente. Este módulo reforzó el ciclo completo desde el desarrollo hasta la publicación final del sitio.

## Módulo 6: Desarrollar una página web de lista de tareas  
Este módulo consistió en un ejercicio práctico en el que se consolidaron los conocimientos previos construyendo una aplicación de lista de tareas. Usamos HTML, CSS y JavaScript para crear una interfaz interactiva con funcionalidades como agregar nuevas tareas, modificar o eliminar elementos y guardar los datos localmente.

## Módulo 7: Su futuro en el desarrollo web: el panorama laboral  
Finalmente, se exploró el ámbito profesional del desarrollo web. Se discutieron las competencias más solicitadas, las diferentes áreas laborales posibles y cómo armar un portafolio llamativo. Además, se brindaron consejos sobre cómo destacarse en procesos de selección y posicionarse dentro del sector tecnológico.

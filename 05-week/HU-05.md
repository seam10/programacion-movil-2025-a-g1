# Todas las ramas para cada HU de deben desarrollar sobre versión develop

Antes de comenzar el desarrollo de cualquier Historia de Usuario (HU), es importante asegurarse de que la rama de trabajo esté actualizada con los últimos cambios de la rama `develop`. Esto garantiza que el desarrollo se realice sobre la versión más reciente del código base y evita conflictos al integrar los cambios.

Pasos a seguir:
1. Cambiar a la rama `develop`:
   ```bash
   git checkout develop
   ```
2. Obtener los últimos cambios de la rama `develop`:
   ```bash
   git pull origin develop
   ```
3. Crear una nueva rama a partir de `develop` con el nombre `feature/HU-{código}`:
   ```bash
   git checkout -b feature/HU-{código}
   ```
4. Desarrollar la HU según los requisitos especificados.
5. Realizar pruebas para asegurar que la funcionalidad implementada funciona correctamente.
6. Hacer un commit de los cambios y subir la rama al repositorio remoto:
   ```bash
   git add .
   git commit -m "Implementación de HU-{código}"
   git push origin feature/HU-{código}
   ```
7. Crear un Pull Request (PR) hacia la rama `develop` y solicitar una revisión de código.

Recuerde seguir las buenas prácticas de desarrollo y mantener un código limpio y bien documentado.
